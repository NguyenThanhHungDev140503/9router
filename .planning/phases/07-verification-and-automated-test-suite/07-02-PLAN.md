# Plan 07-02: ReAct Loop E2E Simulation, NPM Scripts, and Strict Regression Gate

## Goal
Implement end-to-end multi-turn ReAct simulation tests against a local mock upstream server, configure root convenience npm test scripts (`npm test`, `npm run test:mcp`, `npm run test:gate`), and update the regression gate to enforce zero-failure for all MCP and Skills test suites.

## Tasks
1. Create `tests/e2e/mcp-react-pipeline.e2e.test.js` simulating real HTTP upstream LLM interaction, MCP tool intercept, tool execution, multi-turn follow-up, and accumulated usage tracking.
2. Update `tests/__baseline__/verify-no-regression.mjs` to enforce strict zero-failure rule for MCP/Skills suites (`unit/mcp-*`, `unit/api-mcp*`, `unit/api-skills*`, `e2e/mcp-*`).
3. Add root `package.json` scripts:
   - `"test"`: `"npm --prefix tests run test"`
   - `"test:mcp"`: `"npm --prefix tests run test -- unit/mcp unit/api unit/skills e2e/mcp"`
   - `"test:gate"`: `"vitest run --reporter=json --outputFile=tests/results.json && node tests/__baseline__/verify-no-regression.mjs tests/results.json"`
4. Run full test gate check and verify that all MCP suites pass with 0 failures and 0 regressions.
