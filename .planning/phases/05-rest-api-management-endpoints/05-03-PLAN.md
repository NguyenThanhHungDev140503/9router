# Phase 5 Plan 03: Custom Skills & Gateway Tool Rules REST APIs

## Goal
Implement `/api/skills`, `/api/skills/[id]`, and `/api/skills/rules` with full CRUD, validation, auth protection, and tag/status filtering.

## User Requirements
- MCP-API-04: Endpoint `/api/skills` (GET, POST, PUT, DELETE) and rules management.

## Proposed Changes
1. **Create `src/app/api/skills/route.js`:**
   - `GET`: List all skills with filtering (`?enabled=`, `?tag=`).
   - `POST`: Create skill (`name`, `description`, `systemPrompt`, `enabled`, `tags`).
2. **Create `src/app/api/skills/[id]/route.js`:**
   - `GET`: Get skill details by ID.
   - `PUT`/`PATCH`: Update skill details or toggle status.
   - `DELETE`: Remove skill from DB.
3. **Create `src/app/api/skills/rules/route.js` and `src/app/api/skills/rules/[id]/route.js`:**
   - `GET`: List all gateway tool rules.
   - `POST`: Create rule (`pattern`, `action`, `skillId`, `priority`, `enabled`).
   - `PUT`/`DELETE`: Update/delete rule.
4. **Unit Tests:**
   - `tests/unit/api/skills.test.js`: Test skills CRUD, rules CRUD, auth checks, and validation error cases.

## Verification
- Run `npx vitest run tests/unit/api/skills.test.js`
