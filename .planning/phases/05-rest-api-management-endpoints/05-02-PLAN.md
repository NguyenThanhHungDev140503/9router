# Phase 5 Plan 02: MCP Tools Inventory & Live Test Execution APIs

## Goal
Implement `/api/mcp/tools` (query cached and live tools with namespacing) and `/api/mcp/test` (ping connection / run test tool execution).

## User Requirements
- MCP-API-02: Endpoint `/api/mcp/tools` to inspect all loaded/cached MCP tools.
- MCP-API-03: Endpoint `/api/mcp/test` for connection test (ping) and live tool execution.

## Proposed Changes
1. **Create `src/app/api/mcp/tools/route.js`:**
   - `GET`: Query all tool caches across enabled/selected servers.
   - Attach metadata: `serverId`, `serverName`, `name`, `namespacedName` (`mcp__<server>__<tool>`), `description`, `inputSchema`.
   - Query filters: `?serverId=uuid&enabledOnly=true`.
2. **Create `src/app/api/mcp/test/route.js`:**
   - `POST`: Handle test actions:
     - `action: "ping"`: If `serverId` given, check process status / trigger probe; if ephemeral server payload given, temporarily start transport/client and verify `initialize` + `tools/list`.
     - `action: "call"`: Execute tool call on specified server with `toolName` and `arguments`.
   - Returns `{ success: true, result, durationMs }` or sanitized error `{ success: false, error, code }`.
3. **Unit Tests:**
   - `tests/unit/api/mcp-tools-test.test.js`: Test tool listing queries, namespacing format, connection ping, tool call dispatch, and error handling.
