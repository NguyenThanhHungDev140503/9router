# Plan: Database Schema & Repositories

## Objective
Thiết lập schema SQLite và các repository CRUD cho MCP Servers, MCP Tools Cache, Skills, và Gateway Tool Rules.

## Tasks
1. Cập nhật `src/lib/db/schema.js` thêm 4 bảng: `mcpServers`, `mcpToolsCache`, `skills`, `gatewayToolRules`.
2. Tăng `SCHEMA_VERSION = 2` trong `src/lib/db/schema.js` và cập nhật `src/lib/db/migrate.js`.
3. Tạo repository `src/lib/db/repos/mcpRepo.js` hỗ trợ đầy đủ CRUD cho server và cache sync tool.
4. Tạo repository `src/lib/db/repos/skillsRepo.js` hỗ trợ đầy đủ CRUD cho skills và gateway tool rules.
5. Export repositories mới trong `src/lib/db/index.js`.
6. Tạo unit test `tests/unit/mcp-skills-db.test.js` và kiểm tra toàn bộ suite test.

## Verification
- Chạy `npm --prefix tests test tests/unit/mcp-skills-db.test.js` pass 100%.
- Chạy full regression test suite pass.
