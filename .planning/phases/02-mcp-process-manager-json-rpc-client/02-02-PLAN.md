<interfaces>
New contracts used by Plans 03–05:
- `loadMcpHostPolicy()` reads host-only registry/allowlist/limits and rejects malformed configuration.
- `validateMcpServerConfig(server, policy)` validates `commandId`, placeholder values, secret-env keys, transport URL, timeout, and shared-process safety.
- `resolveStdioLaunch(server, policy)` returns `{ command, args, env, maxBufferSize }`; no server `command` or `args` field reaches spawn.
- `assertMcpRemoteUrl(url, { privateEndpointAllowlist, resolveHost })` retains `assertPublicUrl()` defaults and checks resolved addresses at connect time.
- `toMcpGatewayError(error, context)` returns exactly `{ code, message, server, tool, retryable }`.
- Policy owns validation and limits only. It never calls `transport.start()`, `client.start()`, or a transport-handle `start()` method; Plan 01 client is sole transport-start owner and Plan 05 manager invokes `await client.start()` before every discovery initialize.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DB/admin config → launch resolver | Persisted data may be malicious or stale; only host policy may authorize executable, templates, and env keys. |
| remote MCP URL → connection factory | Remote URL/hostname crosses from saved configuration to outbound network access. |
| MCP error/result → gateway consumer | Server-controlled stderr/result content can contain secrets, URLs, or excessive data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Elevation of Privilege | `policy.js` stdio resolver | mitigate | Host command-ID registry, schema-validated placeholders, minimal env, and no shell execution. |
| T-02-05 | Elevation of Privilege | `assertMcpRemoteUrl` | mitigate | Public HTTPS default; exact private allowlist plus resolved-address validation at connect/reconnect. |
| T-02-06 | Information Disclosure | `errors.js` | mitigate | Fixed sanitized envelope and explicit capped/truncated output; strip secrets, URLs, stderr, args, and raw result. |
| T-02-07 | Denial of Service | policy limits | mitigate | Export hard timeout, process, queue, concurrent-call, and output limits for manager enforcement. |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | No package install in this plan. |
</threat_model>
