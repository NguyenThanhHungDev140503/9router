<interfaces>
New contract consumed by `McpProcessManager`:
- `await createMcpTransport(server, { policy, resolveHost })` validates then creates one raw SDK transport for `stdio` or preferred `http`.
- HTTP factory result carries `createLegacyFallback()`; manager may call it only after a classified Streamable HTTP initialization compatibility failure.
- Returned handle exposes `transport`, `transportKind`, `start()`, and idempotent `close()`.
- Factory preserves raw transport `onerror` and `onclose` hooks without assigning them; `McpJsonRpcClient` binds those hooks and forwards manager-owned `onTransportLifecycle({ type, code, retryable })`.
- Factory never imports browser/SSE session code and never invokes `McpJsonRpcClient`.
</interfaces>
</context>
