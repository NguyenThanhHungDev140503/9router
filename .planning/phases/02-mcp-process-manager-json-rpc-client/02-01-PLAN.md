<interfaces>
New public contract consumed by `processManager.js`:
- `new McpJsonRpcClient(transport, { onNotification, onTransportLifecycle })`
- `await client.start()` is sole code path that invokes supplied `transport.start()`; it memoizes its promise so underlying transport starts at most once.
- `client.initialize(params, { timeoutMs })` returns `initializeResult`, validates `initializeResult.protocolVersion`, calls `transport.setProtocolVersion?.(initializeResult.protocolVersion)`, and does not send `notifications/initialized`.
- `client.notifyInitialized()` sends only `notifications/initialized`; it is valid only after successful `initialize()`.
- `client.listTools({ timeoutMs })`
- `client.callTool(name, arguments_, { timeoutMs })`
- `client.close(reason)`

Every outbound request ID is `crypto.randomUUID()` string. `client` uses raw SDK transports only; it must not import or instantiate SDK high-level `Client`.
`listTools()` and `callTool()` reject pre-lifecycle use; they run only after `start()`, validated initialize/protocol application, and `notifyInitialized()`. Manager calls exactly `await client.start()` once before each discovery `initialize` for initial, reconnect, recovery, and legacy-fallback connections. Manager never calls `transport.start()` or `handle.start()`.
`onTransportLifecycle(event)` is manager-owned and receives only `{ type: "error" | "close", code, retryable: true }`; it runs asynchronously after client rejects affected pending work. It must never receive raw `Error`, stderr, URL, environment, arguments, or result data.
</interfaces>
