# Plan 08-01: SQLite Database Schema & Migration 003 for Hermes & Swarm

## Objective
Define the complete SQLite schema and create migration `003-hermes-swarm.js` supporting all 11 new tables for Hermes Bot instances, task queue, blackboard memories, swarm sessions, ant pheromones, colony iterations, convergence metrics, and execution steps.

## Context & Details
- Target database: SQLite with WAL mode (`src/lib/db/`).
- Tables to define in `src/lib/db/schema.js`:
  1. `hermesBots`: Bot profiles, role definitions, model combo bindings, tool whitelist, capability weights.
  2. `hermesTasks`: Task dispatch queue, assigned bot, status (`pending`, `assigned`, `running`, `completed`, `failed`), retry state, error payload.
  3. `hermesTaskSteps`: Step-level execution trace for each task.
  4. `blackboard`: Collective knowledge blackboard, tags, category (`fact`, `code_snippet`, `hypothesis`, `critique`, `solution`), validity score.
  5. `blackboardLinks`: Bidirectional/graph links between blackboard items with relation types.
  6. `blackboardRevisions`: Audit log of edits, revisions, and content changes to blackboard entries.
  7. `swarmSessions`: Swarm coordination sessions, strategy, status, target objective.
  8. `swarmBots`: Many-to-many link between swarm sessions and participant bots.
  9. `swarmPheromones`: Ant colony pheromone trails, decay rates, deposit amounts, reinforcement values.
  10. `swarmColonyIterations`: Iteration cycles of ACO exploration vs exploitation.
  11. `swarmConvergenceMetrics`: Convergence tracking over iterations (variance, consensus score).
- Create migration `src/lib/db/migrations/003-hermes-swarm.js` with version 3 applying `TABLES` definition and custom indices.
- Ensure `src/lib/db/migrate.js` detects and runs migration 003 cleanly in migration chain.

## Tasks
1. Update `src/lib/db/schema.js`:
   - Add schema definitions for all 11 tables with column types, defaults, and primary/foreign keys.
   - Add performance indexes (status, bot_id, swarm_id, task_id, tags, decay/timestamp).
2. Create migration file `src/lib/db/migrations/003-hermes-swarm.js`:
   - Implement `up(db)` applying `buildCreateTableSql` for the 11 tables and registering their indexes.
   - Implement clean rollback/migration handling.
3. Update `src/lib/db/migrate.js` if necessary to register migration 003 in sequence.
4. Create test suite `tests/unit/hermes-schema-migration.test.js`:
   - Verify all 11 tables created properly on SQLite memory/temp DB.
   - Verify table structure, column constraints, default values, and index creation.
   - Verify migration chain 001 -> 002 -> 003 executes without errors.

## Verification
- Run `npx vitest run tests/unit/hermes-schema-migration.test.js` to ensure 100% test pass.
- Run `npx vitest run tests/unit/db-migration-chain.test.js` to ensure no regression in existing migrations.
