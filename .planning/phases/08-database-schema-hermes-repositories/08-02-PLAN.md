# Plan 08-02: Hermes Repositories & Data Access Layer

## Objective
Implement comprehensive repository classes and functions (`hermesRepo`, `swarmRepo`, `blackboardRepo`) providing strongly-typed, sanitized, and query-optimized CRUD, search, and aggregation operations across all 11 Hermes and Swarm tables, re-exported through `src/models/index.js`.

## Context & Details
- Architecture follows existing patterns in `src/lib/db/repos/mcpRepo.js` with prepared statements and JSON serialization/deserialization.
- Repositories to build:
  1. `hermesRepo.js`:
     - Bot CRUD: `getBots()`, `getBotById(id)`, `createBot(bot)`, `updateBot(id, bot)`, `deleteBot(id)`
     - Task CRUD & Queue: `getTasks(filter)`, `getTaskById(id)`, `createTask(task)`, `updateTaskStatus(id, status, result)`, `claimNextPendingTask(botId, capabilities)`, `failTask(id, error)`
     - Step Logging: `recordTaskStep(taskId, stepData)`, `getTaskSteps(taskId)`
  2. `swarmRepo.js`:
     - Swarm Session CRUD: `getSwarmSessions(filter)`, `getSwarmSessionById(id)`, `createSwarmSession(session)`, `updateSwarmSession(id, updates)`, `deleteSwarmSession(id)`
     - Swarm Membership: `addBotToSwarm(swarmId, botId, role)`, `removeBotFromSwarm(swarmId, botId)`, `getSwarmBots(swarmId)`
     - Pheromone Trails: `depositPheromone(swarmId, pathKey, amount, meta)`, `decayPheromones(swarmId, decayFactor)`, `getPheromones(swarmId, minStrength)`
     - Colony Iteration & Convergence: `recordColonyIteration(iterationData)`, `getColonyIterations(swarmId)`, `recordConvergenceMetric(metricData)`, `getConvergenceHistory(swarmId)`
  3. `blackboardRepo.js`:
     - Memory CRUD: `getBlackboardEntries(filter)`, `getBlackboardEntryById(id)`, `createBlackboardEntry(entry)`, `updateBlackboardEntry(id, updates, authorId)`, `deleteBlackboardEntry(id)`
     - Tag & Semantic Search: `searchBlackboard(query, tags, category, minScore)`
     - Graph Links: `linkBlackboardEntries(sourceId, targetId, relationType, weight)`, `getBlackboardLinks(entryId)`, `getBlackboardGraph(swarmId)`
     - Revisions: `getEntryRevisions(entryId)`
- Centralize repository exports in `src/lib/db/repos/index.js` and re-export top-level functions in `src/models/index.js`.

## Tasks
1. Create `src/lib/db/repos/hermesRepo.js` with full CRUD for bots, tasks, steps, and transactional status transitions.
2. Create `src/lib/db/repos/swarmRepo.js` with full CRUD for swarm sessions, bot associations, pheromone trails, iterations, and convergence records.
3. Create `src/lib/db/repos/blackboardRepo.js` with full CRUD for blackboard entries, graph links, revisions, and tag/keyword search.
4. Update `src/lib/db/repos/index.js` and `src/models/index.js` to export all repository interfaces.
5. Create comprehensive unit tests in `tests/unit/hermes-repositories.test.js`:
   - Test bot lifecycle & configuration serialization.
   - Test task state transitions, retry counter, step execution history.
   - Test swarm lifecycle, member assignment, and ant pheromone decay algorithms.
   - Test blackboard entry creation, revisions history, and bidirectional graph linking.

## Verification
- Run `npx vitest run tests/unit/hermes-repositories.test.js` to verify all repository operations pass.
- Run `npm test` to verify complete test suite pass across all unit and integration tests.
