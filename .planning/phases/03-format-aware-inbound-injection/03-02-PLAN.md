<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client headers → selection | `x-mcp-servers` is untrusted client input that can only narrow gateway injection. |
| Cached tool/skill config → selector | Trigger words, descriptions, modes, and skill prompts may contain malformed or adversarial text. |
| Skill XML → upstream model | Gateway-generated XML joins client-owned system instructions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Elevation of Privilege | `x-mcp-servers` parser | mitigate | Interpret header as restrictive allow-list only; intersect with enabled configured servers and never let header enable unknown/disabled entries. |
| T-03-06 | Denial of Service | `selectInboundMcp` | mitigate | Import `MAX_INJECTED_TOOLS = 30` only from `open-sse/config/mcpConstants.js`; zero-match `auto` returns no MCP tools; malformed entries are skipped. |
| T-03-07 | Tampering | XML skill prompt | mitigate | Escape skill names, preserve client system text with copy-on-write, and detect deterministic gateway marker so retries retain one injected block. |
| T-03-08 | Information Disclosure | diagnostics | mitigate | Return sanitized reason codes/counts only; never log raw header, prompt, schema, or skill system-prompt text. |
| T-03-SC | Tampering | package installs | accept | No package install in this plan; no supply-chain change. |
</threat_model>
