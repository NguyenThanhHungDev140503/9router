<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SQLite MCP cache → request injector | Cached tool names, descriptions, and JSON Schemas originate from external MCP servers. |
| Client request → injector merge | Client-owned tools must not be changed or shadowed by gateway tools. |
| Injector → upstream provider | Provider-specific schema shape must remain valid and token-bounded. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | `namespaceToolName` | mitigate | Sanitize server/tool segments, require nonempty generated `mcp__{server}__{tool}` name, and skip generated-name collisions with client or MCP tools. |
| T-03-02 | Tampering | schema minifier | mitigate | Deep-copy cached schemas; strip `$schema`, empty titles, nonessential metadata, and unsupported Gemini fields; never mutate source cache/body. |
| T-03-03 | Information Disclosure | diagnostics | mitigate | Never log raw cached schema descriptions or request prompt text; report only sanitized counts/reason codes. |
| T-03-04 | Denial of Service | conversion loop | mitigate | Skip malformed candidates and retain no-op identity for zero selected tools; Plan 02 applies global `MAX_INJECTED_TOOLS = 30`. |
| T-03-SC | Tampering | package installs | accept | No package install in this plan; no supply-chain change. |
</threat_model>
