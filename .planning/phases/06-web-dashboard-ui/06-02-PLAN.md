# Plan 06-02: MCP Tool Inspection & Live Execution Modal

## Goal
Xây dựng Modal kiểm tra (Inspect) danh sách Tools trả về từ MCP Server và thực thi trực tiếp (Test Execute) với tham số JSON, gọi endpoint `/api/mcp/test` và hiển thị kết quả JSON trả về / thông báo lỗi trực quan.

## Tasks

### Task 1: Xây dựng `McpToolInspectorModal.js`
- **Path**: `src/app/(dashboard)/dashboard/skills/components/McpToolInspectorModal.js`
- **Mô tả**:
  - Khi mở modal với một `serverId`:
    1. Tự động fetch danh sách tools của server đó từ `GET /api/mcp/tools?serverId=${serverId}` (hoặc lấy từ server object nếu đã cache).
    2. Dropdown / danh sách bên trái hoặc phía trên để chọn tool cần inspect/test.
    3. Hiển thị thông tin Tool: Tool Name, Description, Input Schema (danh sách properties, required fields, types).
    4. Argument Editor: Cung cấp JSON Editor (hoặc form template tự sinh từ schema) cho người dùng nhập arguments.
    5. Nút "Execute Tool": Gửi `POST /api/mcp/test` với body `{ serverId, toolName, arguments: parsedArgs }`.
    6. Response Panel: Hiển thị trạng thái loading spinner khi đang chạy, hiển thị kết quả trả về `result` dưới dạng formatted JSON có nút Copy to Clipboard, hoặc hiển thị `error` (code, message, details) nếu thất bại.
- **Verification**: Chọn tool, nhập argument, click "Execute", hiển thị đúng kết quả trả về từ Gateway JSON-RPC execution.

### Task 2: Tích hợp Inspector Modal vào `McpServersTab.js`
- **Path**: `src/app/(dashboard)/dashboard/skills/components/McpServersTab.js`
- **Mô tả**:
  - Gắn sự kiện click "Inspect / Test Tools" ở từng MCP Server card để mở `McpToolInspectorModal`.
  - Quản lý state `inspectingServer` và `showInspectorModal`.
- **Verification**: Click Inspect từ bất kỳ server nào mở đúng modal với context của server đó.
