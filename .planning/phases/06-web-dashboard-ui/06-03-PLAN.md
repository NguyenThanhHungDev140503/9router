# Plan 06-03: Custom Skills Tab & Gateway Tool Rules UI

## Goal
Xây dựng giao diện cho tab "Custom Skills" gồm danh sách skills, tạo/sửa prompt skill qua modal, quản lý tags, toggle trạng thái kích hoạt, và phần quản lý Gateway Tool Rules (`allow`, `deny`, `inject_skill`).

## Tasks

### Task 1: Xây dựng `SkillModal.js`
- **Path**: `src/app/(dashboard)/dashboard/skills/components/SkillModal.js`
- **Mô tả**:
  - Modal tạo mới và chỉnh sửa Custom Skill.
  - Fields: Name (required), Description, System Prompt (multiline textarea, required), Tags (input thêm tag dạng chip, xóa chip), Enabled checkbox/toggle.
  - Form validation và gửi `POST /api/skills` (create) hoặc `PUT /api/skills/[id]` (update).
- **Verification**: Tạo mới skill và cập nhật skill thành công, dữ liệu hiển thị ngay lập tức.

### Task 2: Xây dựng `GatewayRulesModal.js`
- **Path**: `src/app/(dashboard)/dashboard/skills/components/GatewayRulesModal.js`
- **Mô tả**:
  - Modal / Sub-view quản lý các quy tắc định tuyến công cụ Gateway (`gatewayToolRules`).
  - Hiển thị bảng danh sách rules hiện có: Pattern (vd: `mcp__filesystem__*`), Action (`allow`, `deny`, `inject_skill`), Associated Skill/Server, Priority, Enabled toggle, Delete button.
  - Form thêm Rule mới: Pattern input, Action dropdown, Skill selector (khi action là `inject_skill`), Server selector, Priority number input.
  - Gửi `POST /api/skills/rules` và `DELETE /api/skills/rules/[id]`.
- **Verification**: Thêm rule mới và xóa rule hoạt động chính xác qua API.

### Task 3: Xây dựng `CustomSkillsTab.js` và tích hợp vào `SkillsPageClient.js`
- **Path**: `src/app/(dashboard)/dashboard/skills/components/CustomSkillsTab.js`, `src/app/(dashboard)/dashboard/skills/SkillsPageClient.js`
- **Mô tả**:
  - `CustomSkillsTab.js`:
    - Danh sách các Custom Skills dạng thẻ (Card) hoặc hàng: Tên, mô tả, badge tags, xem trước đoạn system prompt, toggle bật/tắt (gọi `PATCH /api/skills/[id]`), nút Edit và nút Delete.
    - Header có nút "New Skill" và nút "Manage Gateway Rules".
  - Tích hợp vào `SkillsPageClient.js` cho phép chuyển đổi mượt mà giữa Tab 1 và Tab 2.
- **Verification**: Toàn bộ luồng quản lý Custom Skills và Gateway Rules hoạt động trơn tru.
