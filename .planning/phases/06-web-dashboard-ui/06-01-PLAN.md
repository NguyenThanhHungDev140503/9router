# Plan 06-01: MCP Servers Tab, Server Modal & Health Badges

## Goal
Tạo giao diện quản lý MCP Server hoàn chỉnh: danh sách Servers, badge trạng thái kết nối có tooltip, modal thêm/sửa Server với form động cho `stdio` (args array, env key-value) và `sse`/`http` (URL), tích hợp toggle bật/tắt tức thì gọi API `/api/mcp/servers`.

## Tasks

### Task 1: Tạo `StatusBadge.js` và `McpServerModal.js`
- **Path**: `src/app/(dashboard)/dashboard/skills/components/StatusBadge.js`, `src/app/(dashboard)/dashboard/skills/components/McpServerModal.js`
- **Mô tả**:
  - `StatusBadge.js`: Hiển thị trạng thái Connected (xanh lá), Stopped (xám), Error (đỏ), Testing/Syncing (vàng). Hỗ trợ tooltip chi tiết khi có lỗi.
  - `McpServerModal.js`: Modal thêm/sửa MCP Server. Chọn transport `stdio` | `sse` | `http`.
    - Khi chọn `stdio`: Hiển thị input Command, Dynamic list editor cho `args` (kèm switch raw JSON), Dynamic Key-Value editor cho `env` variables (kèm switch raw JSON).
    - Khi chọn `sse` hoặc `http`: Hiển thị input URL (validate HTTP/HTTPS) và custom headers editor.
- **Verification**: Form validate đầy đủ dữ liệu trước khi submit POST/PUT tới `/api/mcp/servers`.

### Task 2: Tạo `McpServersTab.js`
- **Path**: `src/app/(dashboard)/dashboard/skills/components/McpServersTab.js`
- **Mô tả**:
  - Renders card list hoặc bảng MCP Servers.
  - Mỗi server card hiển thị: tên server, transport badge, status badge, danh sách tool count, switch enable/disable (optimistic toggle gọi `PUT /api/mcp/servers/[id]`).
  - Action buttons: "Edit", "Inspect Tools & Test", "Delete" (mở ConfirmModal).
  - Nút "Add MCP Server" mở `McpServerModal`.
- **Verification**: Tải danh sách từ `/api/mcp/servers`, toggle trạng thái không reload trang, xóa server thành công.

### Task 3: Cập nhật `page.js` và `SkillsPageClient.js`
- **Path**: `src/app/(dashboard)/dashboard/skills/page.js`, `src/app/(dashboard)/dashboard/skills/SkillsPageClient.js`
- **Mô tả**:
  - `page.js`: Server Component bọc `SkillsPageClient.js`.
  - `SkillsPageClient.js`: Quản lý 2 tabs (`MCP Servers` và `Custom Skills`), lưu active tab, refresh trigger giữa các components.
- **Verification**: Chuyển đổi qua lại giữa các tabs mượt mà, render `McpServersTab` mặc định.
