## Data Storage

**Databases:**
- SQLite (Local Embedded Database)
  - Connection: Driver chain (`bun:sqlite` -> `better-sqlite3` -> `node:sqlite` -> `sql.js`) managed in `src/lib/db/driver.js`
  - Path: `DATA_DIR/9router.db` (defaults to `~/.9router/9router.db` or `/var/lib/9router/9router.db`)
  - Schema & Migrations: Declarative schema in `src/lib/db/schema.js`, auto-sync and numbered migrations in `src/lib/db/migrate.js` and `src/lib/db/migrations/`
  - Repositories: `src/lib/db/repos/` (settings, providerConnections, providerNodes, keys, combos, modelAliases, proxyPools, pxpipe)

**Usage & Audit Logs:**
- File-based JSON & append-only log: `~/.9router/usage.json` and `~/.9router/log.txt` (handled by `src/lib/usageDb.js`)
- Request detail DB: `src/lib/requestDetailsDb.js` (in-memory LRU / SQLite storage with sensitive header and body redaction)

**File & Certificate Storage:**
- MITM Root CA & Host SSL certificates stored in `~/.9router/mitm/ca/` (generated by `node-forge` / `selfsigned`)

## Authentication & Identity

**Dashboard Authentication:**
- Local Admin Password: Saved in DB / `INITIAL_PASSWORD` env, hashed with `bcryptjs`
- JWT Session: HttpOnly session cookie (`9router_session`) signed with `jose` using `JWT_SECRET`
- Enterprise SSO: SAML 2.0 Identity Provider integration via `@node-saml/node-saml` (`src/lib/auth/saml.js`) and OIDC (`src/lib/auth/oidc.js`)
- Login Rate Limiting: IP-based sliding window brute force protection (`src/lib/auth/loginLimiter.js`)

**Gateway API Security:**
- API Key verification: Configured in dashboard or enforced via `REQUIRE_API_KEY=true` (`x-api-key` or `Authorization: Bearer <key>`)
- Peer Trust Verification: Internal server secret (`NINEROUTER_PEER_TOKEN`) in `custom-server.js` to prevent `X-Forwarded-For` and `x-9r-real-ip` spoofing

**OAuth Integrations:**
- xAI / Grok OAuth 2.0 with PKCE & refresh tokens (`src/lib/oauth/providers/xai.js`)
- Antigravity OAuth client with automatic token rotation (`src/lib/oauth/providers/antigravity.js`)
- Kiro AWS Builder ID / External IdP authentication (`src/lib/oauth/kiroExternalIdp.js`)
- Cursor, Copilot, GitHub, Devin, Qoder token extractors and auto-refresh services

## Networking & Remote Access

**Tunnel Providers:**
- Cloudflare Tunnel: Integrated `cloudflared` binary manager with auto-download and process supervisor (`src/lib/tunnel/cloudflare/`)
- Tailscale: Native Tailscale Serve / Funnel integration (`src/lib/tunnel/tailscale/`)

**Outbound Proxy & Proxy Pools:**
- Supports `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY` (SOCKS5), `NO_PROXY` via `socks-proxy-agent` and `src/lib/network/outboundProxy.js`
- Custom Proxy Pools with round-robin, failover, and latency health checks (`src/lib/network/proxyPool.js`)

**MITM Interception Proxy:**
- Local transparent HTTP/HTTPS forward proxy on port 20129 / custom port for intercepting IDE AI plugins (Cursor, Copilot, Antigravity, Kiro) without altering client config files (`src/mitm/`)
